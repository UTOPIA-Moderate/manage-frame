# manage-frame 需求文档

## 一、项目概述

### 1.1 项目定位

企业级中后台管理框架，为开发者提供一套完整、高效、可扩展的中后台解决方案。

### 1.2 核心目标

- 前端：复用 react-admin 的前端页面和交互逻辑
- 后端：基于 Spring Boot 重构，使用 PostgreSQL 数据库
- 配置：所有配置文件收敛到 Nacos 配置中心，实现配置与代码分离

### 1.3 技术选型

| 层级 | 技术选型 | 说明 |
|------|---------|------|
| 前端框架 | React 18 + Umi 4 + Ant Design 5 + TypeScript | 复用 react-admin |
| 后端架构 | Spring Cloud 2023.x 微服务 | 模块化设计 |
| 服务网关 | Spring Cloud Gateway | 统一入口 |
| 注册/配置中心 | Nacos | 服务发现 + 配置中心 |
| 数据库 | PostgreSQL | 各服务独立库 |
| 缓存 | Redis | 会话/数据缓存 |
| ORM | MyBatis-Plus 3.5.x | 简化 CRUD |
| 服务通信 | Open Feign | 服务间 HTTP 调用 |
| 链路追踪 | Spring Cloud Sleuth + Zipkin | 请求链路追踪 |
| 构建工具 | pnpm (前端) / Maven (后端) | - |

### 1.4 微服务模块规划

```
manage-frame/
├── manage-gateway/      # API 网关
├── manage-auth/         # 认证服务（登录/注销/Token/SSO）
├── manage-system/       # 系统服务（用户/角色/菜单/日志）
├── manage-job/         # 定时任务服务（XXL-Job）
├── manage-file/        # 文件服务（S3 存储）
├── manage-common/       # 公共模块（工具类/异常/枚举）
└── manage-web/         # 前端（复用 react-admin）
```

### 1.5 服务职责

| 服务 | 端口 | 职责 |
|------|------|------|
| manage-gateway | 8080 | 请求路由、限流、鉴权 |
| manage-auth | 8081 | 登录认证、Token 颁发、SSO 单点登录 |
| manage-system | 8082 | 用户、角色、菜单、日志管理 |
| manage-job | 8083 | 定时任务管理（XXL-Job 执行器） |
| manage-file | 8084 | 文件上传、存储（S3 协议） |
| manage-common | - | 公共代码（工具类/异常/枚举/Feign客户端/实体类），被其他服务依赖 |

## 五、配置管理（Nacos）

### 5.1 Nacos 角色

- **配置中心**：所有服务的配置文件统一管理
- **注册中心**：各服务启动后自动注册到 Nacos

### 5.2 配置结构

每个微服务在 Nacos 中有独立的配置文件，共享配置通过共享配置集（shared-configs）引用。

### 5.3 Nacos 命名空间与分组

| 配置 | 值 | 说明 |
|------|------|------|
| 命名空间 | manage-frame | 用于隔离不同环境/项目 |
| 分组 | DEFAULT_GROUP | 默认分组 |

所有服务的 `bootstrap.yml` 配置：

```yaml
spring:
  cloud:
    nacos:
      config:
        namespace: manage-frame
        group: DEFAULT_GROUP
      discovery:
        namespace: manage-frame
        group: DEFAULT_GROUP
```

### 5.4 链路追踪配置

Zipkin 配置（Nacos shared-configs）：

```yaml
spring:
  zipkin:
    base-url: ${ZIPKIN_HOST:localhost}:9411
  sleuth:
    sampler:
      probability: 1.0
```

### 5.5 S3 存储配置

文件存储通过 `manage-file-storage.yml` 集中管理，支持动态切换：

```yaml
# 存储类型：minio / s3 / oss / cos
storage:
  type: ${STORAGE_TYPE:minio}
  bucket-name: ${STORAGE_BUCKET:manage-frame}

# MinIO 配置（本地开发）
minio:
  endpoint: ${MINIO_ENDPOINT:http://localhost:9000}
  access-key: ${MINIO_ACCESS_KEY:minioadmin}
  secret-key: ${MINIO_SECRET_KEY:minioadmin}

# AWS S3 配置（生产）
s3:
  region: ${AWS_REGION:ap-northeast-1}
  endpoint: ${AWS_S3_ENDPOINT:}
  access-key: ${AWS_ACCESS_KEY:}
  secret-key: ${AWS_SECRET_KEY:}

# 阿里云 OSS 配置
oss:
  endpoint: ${OSS_ENDPOINT:}
  access-key: ${OSS_ACCESS_KEY:}
  secret-key: ${OSS_SECRET_KEY:}
  bucket-name: ${OSS_BUCKET:}

# 腾讯云 COS 配置
cos:
  region: ${COS_REGION:}
  secret-id: ${COS_SECRET_ID:}
  secret-key: ${COS_SECRET_KEY:}
  bucket-name: ${COS_BUCKET:}
```

### 5.6 SSO 配置

SSO 配置通过 `manage-auth-sso.yml` 管理：

```yaml
sso:
  enabled: ${SSO_ENABLED:true}
  type: ${SSO_TYPE:cas}  # cas / oauth2 / oidc

# CAS 配置
cas:
  server-url: ${CAS_SERVER_URL:}
  client-url: ${CAS_CLIENT_URL:}

# OAuth2 配置
oauth2:
  server-url: ${OAUTH2_SERVER_URL:}
  client-id: ${OAUTH2_CLIENT_ID:}
  client-secret: ${OAUTH2_CLIENT_SECRET:}

# OIDC 配置
oidc:
  issuer: ${OIDC_ISSUER:}
  client-id: ${OIDC_CLIENT_ID:}
  client-secret: ${OIDC_CLIENT_SECRET:}
```

### 5.8 bootstrap.yml 基础配置

各服务基础 bootstrap.yml（以 auth 服务为例）：

```yaml
spring:
  application:
    name: manage-auth
  cloud:
    nacos:
      config:
        server-addr: ${NACOS_HOST:localhost}:8848
        namespace: ${NACOS_NAMESPACE:public}
        group: ${NACOS_GROUP:DEFAULT_GROUP}
        file-extension: yml
        refresh-enabled: true
        shared-configs:
          - data-id: manage-log.yml
            group: ${NACOS_GROUP:DEFAULT_GROUP}
            refresh: true
          - data-id: manage-swagger.yml
            group: ${NACOS_GROUP:DEFAULT_GROUP}
            refresh: true
          - data-id: manage-biz.yml
            group: ${NACOS_GROUP:DEFAULT_GROUP}
            refresh: true
      discovery:
        server-addr: ${NACOS_HOST:localhost}:8848
        namespace: ${NACOS_NAMESPACE:public}
        group: ${NACOS_GROUP:DEFAULT_GROUP}
```

各服务只需修改 `spring.application.name`，其他保持一致。

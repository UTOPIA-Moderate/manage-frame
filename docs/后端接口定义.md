# manage-frame 后端接口定义

> 基于 react-admin 项目后端接口，适配 Spring Cloud 微服务架构

---

## 一、统一响应结构

### 响应 DTO

```typescript
// 成功响应
{
  "code": 200,
  "msg": "操作成功！",
  "data": { ... }
}

// 分页响应
{
  "code": 200,
  "msg": "操作成功！",
  "data": {
    "page": 1,
    "pageSize": 10,
    "total": 100,
    "list": [ ... ]
  }
}

// 失败响应
{
  "code": 500,
  "msg": "错误信息",
  "data": null
}
```

### 通用响应码

| code | 说明 |
|------|------|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未登录或 Token 过期 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

## 二、认证模块 (manage-auth)

### 2.1 用户登录

```
POST /api/auth/login
Content-Type: application/json
```

**请求参数：**

```typescript
{
  type: "account",           // string, 登录类型：account | phone
  user_name?: "admin",      // string, 用户名（account 必填）
  password?: "abc123",      // string, 密码（account 必填）
  phone?: "13800138000",    // string, 手机号（phone 必填）
  verifyCode?: "v4au"       // string, 图形验证码
}
```

**响应：**

```typescript
{
  "code": 200,
  "msg": "操作成功！",

}
```
